    Plugin copy, labels and icons (CLV-85)¶

    Status: spec for one calvin-plugins lane. Source: calvin-plugins origin/main (209ff2b), the PluginMetadata(...) in each plugin.py, read with ast. Renderer contract: CLV-74 (label = field label; description = the hint under the field; hidden skipped). Copy rules: settings audit §5 and the no-developer-words table (#193). midnight-theme 2.0.0 is in the themes audit §4 and isn't repeated here.

    1. Findings¶

    • No field in any of the 14 plugins sets label (54 fields). Every form shows the description as the label, the hint line is empty, and some descriptions are long sentences with URLs and defaults in them.
    • Nothing is required, so a form saves without its address or API key and then fails later.
    • Names and descriptions mix styles: "Mealie Meal Plan", "Email (IMAP)", "Yr.no Weather", URLs inside descriptions, and "Demonstrates event system usage".
    • No plugin sets icon. The contract only allows an emoji or an image file. Emoji render differently per OS and kiosk font (the frontend audit counted 17 emoji-as-icon in the host).
    • test-plugin and test-plugin-frontend are in the catalog. A family would see "Test Plugin" in "Add a web page or app".
    • instance_label (used in "Add {label}" titles) is Title Case or missing.

    2. Decisions (owner approved P1 and P2, 2026-10-31)¶

    • P1. Icons are mdi names (recommended): icon: "mdi:<name>". The host resolves it from a curated map in frontend/src/utils/pluginIcon.js (about 30 names, imported individually from @mdi/js, so the bundle grows by a few KB rather than the whole set). An unknown name or an emoji falls back to the first letter, as today. A plugin that needs its own mark may still ship frontend/icon.svg, monochrome and drawn with currentColor. This is a small host change in the same lane as the plugin edits.
    • P2. Test plugins leave the catalog (recommended): plugins.json marks them "catalog": false. They stay installable from the repo for development, and the catalog list filters them out.

    3. Names, descriptions, icons, instance labels¶

    Description = one sentence for the picker tile: what you see and what it needs. No URLs, no "Calvin", no brand claims.

    Plugin name description icon instance_label
    chromecast Chromecast What's playing on a Chromecast or Google speaker. mdi:cast speaker
    image-processor Photo resizer Shrinks large uploaded photos and makes thumbnails. mdi:image-auto-adjust (none; single instance)
    imap Photos from email Saves photo attachments from an email inbox to Local photos. mdi:email-outline email account
    immich Immich Albums from your Immich photo server. mdi:image-multiple Immich album
    lychee Lychee Albums from your Lychee photo server. mdi:folder-image Lychee album
    mealie Mealie This week's meal plan from your Mealie server. mdi:silverware-fork-knife Mealie server
    nasa-apod NASA picture of the day NASA's astronomy picture of the day, plus past ones. mdi:telescope (none)
    picsum Random photos Random photos from Picsum. Nothing to set up. mdi:shuffle-variant (none)
    sl_departures SL departures Next departures from a Stockholm public transport stop. mdi:bus-clock stop
    system-monitor System monitor CPU, memory, disk and temperature of the Calvin server. mdi:gauge (none)
    test-plugin Test plugin For plugin developers: checks that installing works. mdi:flask-outline (none) (P2: not in catalog)
    test-plugin-frontend Test plugin with a page For plugin developers: checks installing a plugin with its own page. mdi:flask-outline (none) (P2)
    unsplash Unsplash Popular photos from Unsplash. Needs a free Unsplash API key. mdi:camera-outline (none)
    yr_weather Weather (Yr) Weather and forecast from the Norwegian Meteorological Institute. mdi:weather-partly-cloudy place

    instance_label is a lowercase noun phrase. The host capitalises the title ("Add Immich album") and uses it as is in sentences.

    4. Fields: label · hint · notes¶

    The hint is optional, one sentence, ending with a full stop. Units go in the hint when the control can't show them. "req" = add required: true. Values in ui.options keep their labels unless listed.

    5. Repo rules (calvin-plugins CI)¶

    Extend test_validate_plugins.py so this can't drift: - every instance_config_schema field has a non-empty label in sentence case (first letter upper, no Title Case words except proper nouns from an allowlist: Immich, Lychee, Mealie, NASA, SL, Unsplash, Yr, Gmail, Outlook, Google, Chromecast, ID, API); - description, if present, is ≤ 120 characters, ends with a full stop, and has no http; - name is ≤ 28 characters; description (plugin) is one sentence, ≤ 90 characters, no http; - icon matches ^mdi:[a-z0-9-]+$ and is in the host's curated list (the list is mirrored in the test); - catalog entries with "catalog": false are excluded from the published list.

    Bump each touched plugin's patch version (copy-only changes are not breaking). The host map for P1 lands in the same lane as one small calvin PR.
