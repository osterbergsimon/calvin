CLV-9 · Admin auth UI

Mockups for docs/design/2026-10-29-clv-9-admin-auth-ui.md. Built with the real Paper and Backlit tokens from theme.css. Every pixel value here maps to a token or to an existing component. The spec decides when they disagree.

A. Settings lock screen

Replaces .settings-body until auth.authenticated. On a touch kiosk (isTouch) the phone hand-off sits beside the card. On a laptop or phone it does not, because the person already has a keyboard.

B. In-place sign-in dialog (401 admin_required)

Opens over whatever is on screen when an admin-only request fails. On a kiosk the phone half deep-links to the Settings page for that action, because signing in on a phone does not unlock the kiosk.

C. Settings › Security: Admin access

A new first section, above Sealed mode. It uses the existing SettingsSection and SettingRow. The change-password form expands inline below its row.
