Kiosk pairing

On the wall, an unpaired screen shows its code in a strip docked to the bottom edge. The dashboard gets shorter by the height of the strip, so nothing is hidden and no button is covered. In Settings › Screens, each screen row says whether it is paired. A new Pairing section holds Pair a screen and Only paired screens, and Add a screen gives a one-time code with its install command.
