Screen power mode

Each screen's Power section starts with one choice, Screen power: Schedule · Always on · External. The hint under it explains the choice. The schedule shows only in Schedule. Screen now says whether the screen is on or off, and who set it and when. Always on has no Screen now row. The household default lives on the Default screen page, and a screen that differs says Changed here.
