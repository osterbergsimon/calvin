# dd9.2 — Kiosk Identity (keystone) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give each kiosk Pi a stable identity it sends to the server, and have the server record/list known kiosks — with zero behavior change for requests that carry no id.

**Architecture:** A new `kiosks` table (Ormar model + Alembic migration) stores a registry row per kiosk. A small `kiosk_registry` service upserts a row (id, hostname, last_seen) on each identified request and lists known kiosks. `GET /api/config` reads an optional `?kiosk=<id>` (+ `?khost=<hostname>`) query param and records the kiosk; the returned config is unchanged (the per-kiosk *merge* is a later child, dd9.3). `setup-kiosk.sh` generates a collision-proof default `CALVIN_KIOSK_ID` and the kiosk's Chromium launches `${CALVIN_BACKEND_URL}/?kiosk=<id>`; the frontend reads that param and threads it onto its API calls.

**Tech Stack:** FastAPI, Ormar ORM + Alembic (SQLite), Pytest (backend), Vue 3 + Pinia + axios, Vitest (frontend), Bash (`scripts/setup-kiosk.sh`).

## Global Constraints

- Backend Python 3.12+, managed with `uv`. Run backend tests with `uv run pytest` from `backend/`.
- Tests build schema via **`alembic upgrade head`**, NOT `metadata.create_all` — every new Ormar model **requires an Alembic migration** and must be added to the model import block in `backend/alembic/env.py`, or its table won't exist in tests.
- All DB writes wrap with `retry_on_db_locked` from `app.utils.db_retry` (SQLite locks under concurrency — house rule).
- Backward compatibility is a hard requirement: a request with **no** `kiosk` param must return exactly today's `GET /api/config` response and touch no new table.
- New API routes register under the `/api` prefix in `backend/app/main.py` (mirror the existing `app.include_router(config.router, prefix="/api", ...)` lines).
- Loguru on the backend (`from loguru import logger`); never stdlib `logging`.
- Frontend network calls go through `axios` (already imported in `frontend/src/stores/config.js`).

```python
"""Registry of known kiosks (per-device settings model — calvin-dd9.2)."""

from datetime import datetime

from loguru import logger

from app.models.db_models import KioskDB
from app.utils.db_retry import retry_on_db_locked


@retry_on_db_locked
async def record_kiosk(kiosk_id: str, hostname: str | None = None) -> None:
    """Upsert a kiosk's registry row. No-op when kiosk_id is empty/None."""
    if not kiosk_id:
        return

    existing = await KioskDB.objects.get_or_none(id=kiosk_id)
    now = datetime.utcnow()
    if existing is None:
        await KioskDB.objects.create(id=kiosk_id, hostname=hostname, last_seen=now)
        logger.info(f"Registered new kiosk: {kiosk_id} (hostname={hostname})")
        return

    existing.last_seen = now
    if hostname:
        existing.hostname = hostname
    await existing.update()


async def list_kiosks() -> list[dict]:
    """Return known kiosks, newest-seen first."""
    rows = await KioskDB.objects.order_by("-last_seen").all()
    return [
        {
            "id": row.id,
            "hostname": row.hostname,
            "lastSeen": row.last_seen.isoformat() if row.last_seen else None,
            "lastAppliedVersion": row.last_applied_version,
        }
        for row in rows
    ]
```

# Compute a collision-proof default kiosk id: <hostname>-<6 hex from machine-id>.
# A stock Pi image defaults hostname to "raspberrypi", so hostname alone collides
# across multiple Pis; the machine-id suffix disambiguates. Falls back to the
# primary NIC MAC, then the Pi CPU serial, if machine-id is unavailable.
compute_default_kiosk_id() {
    local host suffix src
    host="${HOSTNAME_OVERRIDE:-$(hostname 2>/dev/null || echo kiosk)}"
    src="${MACHINE_ID_OVERRIDE:-}"
    if [ -z "$src" ] && [ -r /etc/machine-id ]; then src="$(cat /etc/machine-id)"; fi
    if [ -z "$src" ]; then
        src="$(cat /sys/class/net/*/address 2>/dev/null | grep -v '00:00:00:00:00:00' | head -n1 | tr -d ':')"
    fi
    if [ -z "$src" ]; then
        src="$(grep -m1 -i Serial /proc/cpuinfo 2>/dev/null | awk '{print $3}')"
    fi
    suffix="$(printf '%s' "$src" | tr -cd 'a-f0-9' | cut -c1-6)"
    [ -n "$suffix" ] || suffix="000000"
    printf '%s-%s\n' "$host" "$suffix"
}

# When sourced for testing, stop here — do not run the setup body below.
[ "${_CALVIN_SOURCE_ONLY:-0}" = "1" ] && return 0 2>/dev/null || true
```

// Per-kiosk identity (calvin-dd9.2). The kiosk's Chromium opens the server URL
// with ?kiosk=<id>; the frontend reads it here and threads it onto API calls so
// the server can register the kiosk (and, later, serve per-kiosk config).

export function getKioskId() {
  try {
    const id = new URLSearchParams(window.location.search).get("kiosk");
    return id && id.trim() ? id.trim() : null;
  } catch {
    return null;
  }
}

export function withKiosk(url) {
  const id = getKioskId();
  if (!id) return url;
  const sep = url.includes("?") ? "&" : "?";
  const host = encodeURIComponent(window.location.hostname || "");
  return `${url}${sep}kiosk=${encodeURIComponent(id)}&khost=${host}`;
}
```
