# dd9.9 — Display-agent applies per-kiosk orientation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Teach the display-agent to fetch its per-kiosk effective config and apply the server-configured orientation via `xrandr` (version-gated, env-escape-hatch aware), so per-kiosk orientation actually takes effect on the Pi.

**Architecture:** Add three units to `deploy/kiosk-agent/calvin_display_agent.py`: a kiosk-id-aware config URL (`fetch_config` targets `/api/kiosks/{id}/config` when `CALVIN_KIOSK_ID` is set), a pure `orientation_to_xrandr` mapping, and an injectable `apply_device_physical(cfg, ...)`; then wire version-gating into the existing `run()` loop so device-physical re-applies only when `deviceConfigVersion` changes.

**Tech Stack:** Python 3 **stdlib only** (urllib/subprocess) — the kiosk Pi has no venv. Tests: pytest, run via `cd backend && uv run pytest ../deploy/kiosk-agent/test_display_agent.py -v`. The test module loads the agent via importlib as `agent` and uses dependency injection (`run(..., fetch=, sleep=, iterations=)`) + monkeypatch.

## Global Constraints

- **Pure stdlib** — no third-party imports in the agent.
- **Orientation → xrandr mapping must match `display_orientation_service` exactly:** `flipped ⇒ "inverted"`; else `portrait ⇒ "left"`; else `"normal"` (landscape/unknown).
- **Escape-hatch precedence:** `CALVIN_DISPLAY_ROTATION` env (non-empty) wins over the server orientation.
- **Gate:** apply only when `applyDisplayRotation` (config, default `True`) is truthy.
- **Config keys read tolerantly** (camelCase + snake_case) via the existing `cfg_get`.
- **Version-gating:** re-apply device-physical only when the config body's `deviceConfigVersion` changed since last apply.
- **Fail-safe:** apply/fetch errors never crash the loop (existing `run()` try/except preserved).
- Reuse existing `apply_rotation(rotation, output)`, `detect_primary_output()`, `cfg_get`, `VALID_ROTATIONS`.
- Lint: the changed agent files must pass the repo's ruff (the controller's pre-merge sweep verifies pre-commit/CI parity).

```python
def _config_url(backend_url, kiosk_id, host):
    """Effective-config URL: per-kiosk endpoint when a kiosk id is set, else global."""
    base = backend_url.rstrip("/")
    if kiosk_id:
        q = urllib.parse.urlencode({"khost": host}) if host else ""
        return f"{base}/api/kiosks/{kiosk_id}/config" + (f"?{q}" if q else "")
    return base + "/api/config"


def fetch_config(backend_url):
    kiosk_id = os.environ.get("CALVIN_KIOSK_ID", "").strip()
    host = os.environ.get("CALVIN_KIOSK_HOSTNAME", "").strip() or socket.gethostname()
    url = _config_url(backend_url, kiosk_id, host)
    with urllib.request.urlopen(url, timeout=HTTP_TIMEOUT) as r:
        return json.load(r)
```

```python
def orientation_to_xrandr(cfg):
    """Map server orientation config to an xrandr rotate value.

    Matches backend display_orientation_service: flipped -> inverted;
    else portrait -> left; else normal (landscape/unknown).
    """
    flipped = cfg_get(cfg, "orientation_flipped", "orientationFlipped", default=False)
    if flipped:
        return "inverted"
    orientation = cfg_get(cfg, "orientation", default="landscape")
    if orientation == "portrait":
        return "left"
    return "normal"


def apply_device_physical(cfg, *, applier=apply_rotation, env=None):
    """Apply device-physical settings (orientation) from the effective config.

    CALVIN_DISPLAY_ROTATION env (device-local escape hatch) wins over the server
    orientation. Gated on applyDisplayRotation (default True).
    """
    if env is None:
        env = os.environ
    if not cfg_get(cfg, "apply_display_rotation", "applyDisplayRotation", default=True):
        return
    env_rotation = env.get("CALVIN_DISPLAY_ROTATION", "").strip()
    rotation = env_rotation or orientation_to_xrandr(cfg)
    output = env.get("CALVIN_DISPLAY_OUTPUT", "").strip() or None
    applier(rotation, output)
```

```python
def run(
    backend_url,
    refresh_seconds,
    *,
    fetch=fetch_config,
    sleep=time_module.sleep,
    iterations=None,
    apply_device=apply_device_physical,
):
    last = None
    last_version = None
    n = 0
    while iterations is None or n < iterations:
        n += 1
        try:
            cfg = fetch(backend_url)
            if not isinstance(cfg, dict):
                raise TypeError(f"expected dict config, got {type(cfg).__name__}")
            version = cfg_get(cfg, "deviceConfigVersion")
            if version != last_version:
                apply_device(cfg)
                last_version = version
            now = now_in(cfg)
            prev = last
            last = reconcile(cfg, now, last)
            if prev != last:
                log(f"display -> {'ON' if last else 'OFF'}")
            secs = seconds_to_next_boundary(cfg, now)
            delay = refresh_seconds if secs is None else max(1, min(secs, refresh_seconds))
        except Exception as e:
            log(f"iteration failed ({e}); keeping display state")
            sleep(BACKOFF_SECONDS)
            continue
        sleep(delay)
```

Note: `apply_device=apply_device_physical` as a default arg requires `apply_device_physical` to be defined **above** `run` in the file.
