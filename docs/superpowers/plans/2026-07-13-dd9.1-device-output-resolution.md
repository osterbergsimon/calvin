# Device-local Output + Resolution (display-agent) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the Calvin display-agent so it applies a per-Pi primary **output** and screen **resolution/mode** device-locally (via xrandr), mirroring the existing rotation path.

**Architecture:** Add a small, isolated `apply_mode(output, resolution)` xrandr helper plus a `_parse_resolution` parser, then wire them into `apply_device_physical` so output+mode apply before rotation. Device-local env vars win over server config; nothing else in the agent restructures. No backend changes — `displayOutput`/`displayResolution` are already in `DEVICE_PHYSICAL_KEYS`, so `deviceConfigVersion` already covers them.

**Tech Stack:** Python 3 standard library only (the Pi has no venv), `xrandr` via `subprocess`, pytest with `monkeypatch`.

## Global Constraints

- **Pure stdlib only** — no third-party imports, no new dependencies (agent runs on the Pi's system Python).
- **Precedence (each setting):** device-local env var → server config → (output only) `detect_primary_output()`. Absent/empty = skip that setting, leave hardware as-is (never force a default).
- **Env keys** (read from `/etc/default/calvin-kiosk`): `CALVIN_DISPLAY_OUTPUT` (already read; xrandr output name) and new `CALVIN_DISPLAY_RESOLUTION`. Server keys (camelCase / snake): `displayOutput`/`display_output`, `displayResolution`/`display_resolution` — read via the existing `cfg_get(cfg, "snake", "camel", default=…)`.
- **Resolution format:** `WIDTHxHEIGHT` or `WIDTHxHEIGHT@RATE` (e.g. `1920x1080`, `1920x1080@60`). Malformed → log a warning and skip the `--mode` argument; never pass a bad mode to xrandr.
- **A configured output is marked `--primary`** (this is the "select primary output" feature; a deliberate extension of today's rotation-only output use).
- **Order:** apply output+mode **before** rotation (a mode change can reset rotation on some drivers), so the existing `apply_rotation` runs last and wins.
- **Rotation stays gated on `applyDisplayRotation` (default True); output/resolution apply independently** of that gate.
- **Never raise / never blank the screen:** `apply_mode` catches xrandr failures (non-zero exit, `FileNotFoundError`, `SubprocessError`), logs, and returns a skip/failure marker; it must never raise out of `apply_device_physical` or crash `run()`.
- **Tests** monkeypatch `agent.subprocess.run` to capture the exact argv list; pytest; pure stdlib. Run with `pytest deploy/kiosk-agent/test_display_agent.py`.

def _parse_resolution(resolution):
    """Parse 'WxH' or 'WxH@RATE' into (mode, rate_or_None). Return None if malformed."""
    m = _RESOLUTION_RE.match(resolution.strip())
    if not m:
        return None
    return m.group(1), m.group(2)


def apply_mode(output, resolution):
    """Select the primary output and optionally set its mode via xrandr.

    output: an explicitly-configured xrandr output name (env/server), or None.
    resolution: 'WxH' or 'WxH@RATE', or None.
    Does nothing when neither is configured. A configured output is marked --primary.
    Returns the argv applied, or None if skipped/failed. Never raises.
    """
    if not output and not resolution:
        return None
    out = output or detect_primary_output()
    if not out:
        log("no connected display output found; cannot set output/mode")
        return None
    argv = ["xrandr", "--output", out, "--primary"]
    if resolution:
        parsed = _parse_resolution(resolution)
        if parsed is None:
            log(f"ignoring invalid resolution {resolution!r} (expected WxH or WxH@RATE)")
        else:
            mode, rate = parsed
            argv += ["--mode", mode]
            if rate:
                argv += ["--rate", rate]
    try:
        r = subprocess.run(
            argv,
            env=dict(os.environ, **X11_ENV),
            capture_output=True,
            text=True,
            timeout=10,
        )
    except (FileNotFoundError, subprocess.SubprocessError) as e:
        log(f"output/mode apply failed ({e})")
        return None
    if r.returncode == 0:
        log(f"output/mode applied: {' '.join(argv[1:])}")
        return argv
    log(f"output/mode apply failed (xrandr rc={r.returncode}): {r.stderr.strip()}")
    return None
```

def apply_device_physical(cfg, *, applier=apply_rotation, mode_applier=apply_mode, env=None):
    """Apply device-physical settings (output/resolution/orientation) from the config.

    Device-local env vars win over server config:
      CALVIN_DISPLAY_OUTPUT     -> output selected as primary / rotation target
      CALVIN_DISPLAY_RESOLUTION -> 'WxH' or 'WxH@RATE'
      CALVIN_DISPLAY_ROTATION   -> xrandr rotate value
    Output+mode apply first (a mode change can reset rotation), then rotation.
    Rotation is gated on applyDisplayRotation (default True); output/resolution are
    independent of that gate.
    """
    if env is None:
        env = os.environ
    output = (
        env.get("CALVIN_DISPLAY_OUTPUT", "").strip()
        or cfg_get(cfg, "display_output", "displayOutput", default="")
        or None
    )
    resolution = (
        env.get("CALVIN_DISPLAY_RESOLUTION", "").strip()
        or cfg_get(cfg, "display_resolution", "displayResolution", default="")
        or None
    )
    mode_applier(output, resolution)
    if cfg_get(cfg, "apply_display_rotation", "applyDisplayRotation", default=True):
        env_rotation = env.get("CALVIN_DISPLAY_ROTATION", "").strip()
        rotation = env_rotation or orientation_to_xrandr(cfg)
        applier(rotation, output)
```
