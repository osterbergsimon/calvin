    dd9.3 — Per-kiosk config store + per-kiosk config endpoints Implementation Plan¶

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: Give each kiosk a per-kiosk override layer and an effective-config endpoint, so a client reads GET /api/kiosks/{id}/config (merged global+overrides, with an ETag), an admin edits GET/PUT /api/kiosks/{id}/overrides, and /api/config becomes global-only.

    Architecture: Pure merge_overrides/device_config_version helpers + DB accessors in kiosk_registry; a build_global_config() helper shared by /api/config and the effective endpoint (DRY); new routes on the existing kiosks router; and a small frontend switch from a query-param appender to a URL selector.

    Tech Stack: FastAPI, Ormar/SQLite, Pytest (uv), Vue 3 + Pinia + axios, Vitest.

    Global Constraints¶

    • Backend Python 3.12+ / uv; run backend tests cd backend && uv run pytest .... Frontend Vitest from frontend/ (npx vitest run ...).
    • Shallow top-level merge only: an override key replaces that whole global key. No recursion, no array merge.
    • Device-physical values are served, not stripped from the effective config.
    • Backward compat: GET /api/config with no identity is byte-identical to today (Mode A). A kiosk with no overrides ⇒ effective config == defaulted global (plus deviceConfigVersion).
    • All DB writes wrap retry_on_db_locked (from app.utils.db_retry).
    • Reuse the existing id-shape gate _KIOSK_ID_RE = re.compile(r"[A-Za-z0-9._-]{1,64}") (in kiosk_registry.py) — validate with .fullmatch.
    • Override payloads validate against the existing ConfigUpdate Pydantic model (extra="allow") in backend/app/api/routes/config.py.
    • Loguru not stdlib logging.
    • After any route change, regenerate the OpenAPI snapshot AND the frontend types (a contract test enforces the snapshot):
    • Backend snapshot: cd backend && UPDATE_OPENAPI_SNAPSHOT=1 uv run pytest tests/contract/test_openapi_snapshot.py
    • Frontend types: cd frontend && npm run gen:api

def merge_overrides(base: dict, overrides: dict | None) -> dict:
    """Shallow top-level merge: each override key replaces that base key wholesale.

    No recursion, no array merge. Returns a new dict; `base` is not mutated.
    """
    if not overrides:
        return dict(base)
    return {**base, **overrides}


def device_config_version(merged: dict) -> str:
    """Stable 16-char hex digest of the device-physical subset of a merged config.

    Same inputs -> same version; any DEVICE_PHYSICAL_KEYS change -> new version;
    non-device-physical changes do not bump it.
    """
    subset = {k: merged.get(k) for k in DEVICE_PHYSICAL_KEYS}
    blob = json.dumps(subset, sort_keys=True, default=str)
    return hashlib.sha256(blob.encode("utf-8")).hexdigest()[:16]

@retry_on_db_locked()
async def set_overrides(kiosk_id: str, overrides: dict) -> None:
    """Upsert the kiosk row and replace its overrides. No-op on malformed id."""
    if not kiosk_id or not _KIOSK_ID_RE.fullmatch(kiosk_id):
        logger.warning(f"Refusing to set overrides for malformed kiosk_id: {kiosk_id!r}")
        return
    now = datetime.utcnow()
    existing = await KioskDB.objects.get_or_none(id=kiosk_id)
    if existing is None:
        await KioskDB.objects.create(id=kiosk_id, last_seen=now, overrides=overrides)
        return
    existing.overrides = overrides
    await existing.update()

    Note: get_overrides returns {} (not None) for a known kiosk whose column is null — callers treat "known but empty" and "no overrides" identically for merging; None means "kiosk unknown" (used by the CRUD GET to 404).

import json

from fastapi import APIRouter, HTTPException, Request, Response
from loguru import logger

from app.api.routes.config import build_global_config
from app.services import kiosk_registry
from app.services.kiosk_registry import (
    _KIOSK_ID_RE,
    device_config_version,
    get_overrides,
    merge_overrides,
)

router = APIRouter()


def _valid_id_or_400(kiosk_id: str) -> None:
    if not _KIOSK_ID_RE.fullmatch(kiosk_id):
        raise HTTPException(status_code=400, detail="Invalid kiosk id")


@router.get("/kiosks")
async def get_kiosks():
    """List known kiosks (id, hostname, last-seen, lastAppliedVersion)."""
    return {"kiosks": await kiosk_registry.list_kiosks()}


@router.get("/kiosks/{kiosk_id}/config")
async def get_kiosk_config(kiosk_id: str, request: Request, khost: str | None = None):
    """Return a kiosk's effective (merged) config; records the kiosk; ETag + 304."""
    _valid_id_or_400(kiosk_id)
    try:
        await kiosk_registry.record_kiosk(kiosk_id, hostname=khost)
    except Exception as exc:
        logger.warning(f"Failed to record kiosk {kiosk_id!r}: {exc}")

    base = await build_global_config()
    overrides = await get_overrides(kiosk_id)
    merged = merge_overrides(base, overrides)
    version = device_config_version(merged)

    if request.headers.get("If-None-Match") == version:
        return Response(status_code=304, headers={"ETag": version})

    merged["deviceConfigVersion"] = version
    return Response(
        content=json.dumps(merged),
        media_type="application/json",
        headers={"ETag": version},
    )

    ### Per-kiosk configuration

Each kiosk reads its **effective config** from `GET /api/kiosks/<id>/config` — the
global config with that kiosk's overrides applied (device-physical values like
rotation included; the browser ignores what it can't act on, the display-agent
applies them). The response carries an `ETag`/`deviceConfigVersion` so a client can
cheaply detect device-physical changes (`If-None-Match` → `304`).

Per-kiosk overrides are edited via `GET/PUT /api/kiosks/<id>/overrides` (a sparse
layer that replaces on PUT). `GET /api/config` is now **global-only** (Mode-A Pis and
the template new kiosks inherit). List known kiosks with `curl http://<server>:8000/api/kiosks`.
